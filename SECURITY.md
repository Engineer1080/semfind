# Security policy

The current experimental release line receives security fixes as development capacity allows.

When private vulnerability reporting is enabled on GitHub, open the repository's **Security** tab and choose **Report a vulnerability**. If the button is unavailable, use a private contact method listed on the maintainer's GitHub profile. Include the affected revision, impact, reproduction steps using synthetic files, and details about your distribution and configuration. Keep personal data, index files, and credentials out of reports.

The maintainer will assess the report, confirm scope where possible, and coordinate a fix and disclosure. Please allow time to investigate before publishing details.
