# Code of conduct

Treat other contributors with respect. Discuss implementation choices using evidence, assume good faith, and respect requests to disengage. Harassment, discriminatory or sexual remarks, personal attacks, threats, and sharing someone's private information without consent are unacceptable.

Maintainers may remove content, limit participation, or block accounts in response to conduct that harms participants. To report a concern privately, contact a repository maintainer through a private channel listed on their GitHub profile. Include the relevant links and describe the behavior. Maintainers should restrict the report to people handling it and protect the reporter's privacy.
